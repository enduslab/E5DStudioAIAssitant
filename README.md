# E5DStudioAIAssitant
##E5DStudio的AI助手 
###1.与E5D Studio配套使用 
###2.需先下载E5D Studio 
###3.不包含内置大模型，需配置用户自己的大模型API，支持标准OpenAI样式API 
###4.用户可通过自然语言，完成E5D Studio的帮助查询、功能操作

##安装方法
------------------------------------------------------------
###1. 双击运行「安装E5DStudioAI助手.lnk」（推荐，图标为 AI 助手图标）或双击 install.bat 运行安装程序。

###2. 在弹出的安装窗口中，点击「浏览...」选择 E5D Studio 安装根目录（即包含 E5DStudio.exe 的目录），或直接在输入框中输入路径。

###3. 点击「开始安装」按钮，等待安装完成。

###4. 安装完成后，桌面会创建快捷方式「E5D Studio (AI助手)」，请通过该快捷方式启动 Studio（启动器会自动管理后端生命周期）。
